# MIVA Open University - COS 106 Term Project
## Student Portfolio & Academic Management Website

**Student Name:** Fatima Hamisu Burah  
**Institution:** MIVA Open University  
**Course:** COS 106 - Introduction to Web Technologies  

---

### Project Overview
This project is a fully functional multi-page website serving as a personal academic portfolio and student management platform for Fatima Hamisu Burah, founder of *Fatash Clothing & More*.

### Included Pages & Features
1. **Homepage (`index.html`)**:
   - Student name, welcome badge, navigation menu, and professional bio snippet.
   - Featured multimedia audio player demonstrating semantic HTML multimedia support.
2. **About Me Page (`about.html`)**:
   - Educational background presented in a structured HTML table.
   - Career aspirations and technical skills list.
   - Hobbies and personal interests grid.
3. **Projects Page (`projects.html`)**:
   - Three sample projects (Fatash Clothing & More E-Commerce Landing Page, MIVA Academic Portal, Personal Development Resource Hub) with descriptions, tags, and simulated demo/repository links.
4. **Academic Planner Page (`planner.html`)**:
   - Interactive task management system powered by JavaScript.
   - Allows adding tasks with due dates, marking tasks as completed, filtering (All, Pending, Completed), and local storage persistence.
5. **Contact Page (`contact.html`)**:
   - Complete contact form with robust JavaScript validation ensuring:
     - No field is empty.
     - Valid email format.
     - Phone number contains strictly digits only.

### Technical Compliance
- **HTML5:** Semantic elements (`<header>`, `<nav>`, `<section>`, `<footer>`), tables, forms, hyperlinks, lists, and multimedia.
- **CSS3:** External stylesheet (`style.css`), CSS Flexbox and Grid, responsive layouts, hover animations, and a consistent color scheme.
- **JavaScript (ES6+):** Event handling, DOM manipulation, form validation regex, arrays, local storage, and dynamic content updates.

### How to Run
1. Extract all files into a local folder.
2. Open `index.html` in any modern web browser.
3. Host on GitHub Pages, Netlify, or Vercel and submit the live URL along with the GitHub repository link.
